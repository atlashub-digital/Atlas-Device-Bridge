## Open-source candidates / external platform references
- [openclaw/openclaw](https://github.com/openclaw/openclaw) · [nodes](https://github.com/openclaw/openclaw/blob/main/docs/nodes/index.md) · [computer use](https://github.com/openclaw/openclaw/blob/main/docs/nodes/computer-use.md) · [camera](https://github.com/openclaw/openclaw/blob/main/docs/nodes/camera.md) — candidate optional node adapter.
- [microsoft/playwright](https://github.com/microsoft/playwright) — browser-targeted UI automation; not universal device control.
- [microsoft/PowerToys](https://github.com/microsoft/PowerToys) — Windows application/desktop capabilities and accessibility inspiration, not a drop-in ADB gateway.

- [Apple App Intents](https://developer.apple.com/documentation/AppIntents) — explicit own-app actions and Shortcuts.
- [Android MediaProjection](https://developer.android.com/media/grow/media-projection) · [AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService) — OS capabilities and permission boundaries.
- [Android TV MediaSession](https://developer.android.com/training/tv/playback/media-session) — owned media playback.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — browser instrumentation, use only with authorized controlled instances.
- [n8n](https://github.com/n8n-io/n8n) — approved workflow integration after trust gateway; not device authority.
