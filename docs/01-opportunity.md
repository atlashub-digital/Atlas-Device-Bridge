# ADB-OPP-001 · Opportunity study and business thesis

**State:** RESEARCH / PROPOSED · **Opened:** 2026-10-10

## Opportunity
An augmented enterprise needs AI workers that can interact with the business's actual operating environment. Existing APIs solve structured tasks; local UIs, devices, kiosks and legacy workflows sometimes lack API coverage. ADB supplies an optional **consent-first capability surface**.

**No change to validated business architecture:** AtlasHub.SI still serves **AI Workforce Managed** and **Enterprise Transformation Build & Transfer / Co-Build**. Device Bridge is a technical module / potential differentiator, not a new unit or compulsory layer. AMF remains independently governed.

## Primary buyers and problem
- SMB using legacy desktop ERP, CRM or workflow with limited API: supervised form filling, visible guidance and safe document intake.
- Clinic: administrative reception tasks on approved systems; never clinical diagnosis or hidden patient data collection.
- Real estate: guided visits, listing entry into CRM via official API preferred; device UI only where integration unavailable.
- Field operations: hands-free guidance, on-device approved media capture and procedures.
- Education / accessibility: self-owned TV or assisted-device experience with transparent usage and age safeguards.

## Business models to validate
- Managed service add-on per enabled device / active session, subject to privacy and actual support cost.
- Build/Transfer on customer's own infrastructure with transferable signed capability manifests.
- Per-site kiosk/tutor deployment with supported hardware bundle.
- Pure advisory/assessment for unsupported devices where no safe automation is feasible.

No prices, performance promises, client deployments, throughput figures or ROI claims until POC and cost baselines.

## Decision gates
P0 — legality/platform review → P1 — on-device consent + safe pairing → P2 — Windows sandbox proof → P3 — cost/UX/safety measured → P4 — only then productization. Android/iOS/TV independently assessed; do not infer one from another.
